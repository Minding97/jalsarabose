# 잘살아보세 MVP 작업 요약

작성일: 2026-06-17
대상: 기획자, 디자이너

## 한 줄 요약

`잘살아보세`는 함께 사는 사람들이 지출과 냉장고 재고를 한곳에서 관리하는 공동생활 앱입니다.

현재는 디자인 적용 전 단계이며, 실제 로그인과 가구 공유가 가능한 MVP 기능 뼈대가 구현되어 있습니다.

## 현재 상태

- 앱 기본 구조 완성
- Firebase 로그인/회원가입 연결
- 가구 생성과 초대 코드 참여 가능
- 지출과 냉장고 항목 등록/수정/삭제 가능
- 홈과 캘린더가 실제 데이터와 연결됨
- 알림 정책과 로컬 알림 예약 준비 완료
- 디자인 QA용 데모 데이터 준비 완료

## 디자인 전 꼭 알아둘 점

1. 현재 UI는 임시 스타일입니다.
2. 기능 흐름과 데이터 구조는 먼저 고정했습니다.
3. 디자인은 `홈`, `캘린더`, `지출`, `냉장고`, `로그인/가구 설정` 순서로 잡으면 됩니다.
4. 화면별 빈 상태, 에러 상태, 로딩 상태가 필요합니다.

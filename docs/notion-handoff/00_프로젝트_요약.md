# 잘살아보세 MVP 작업 요약

작성일: 2026-06-17
대상: 기획자, 디자이너

## 한 줄 요약

`잘살아보세`는 함께 사는 사람들이 지출과 냉장고 재고를 한곳에서 관리하는 공동생활 앱입니다.

현재는 주요 기능과 반응형 디자인이 구현된 내부 MVP이며, 실제 기기·릴리즈 Firebase·스토어 준비를 진행하는 단계입니다.

## 현재 상태

- 앱 기본 구조 완성
- Firebase 로그인/회원가입 연결
- 가구 생성과 초대 코드 참여 가능
- 지출과 냉장고 항목 등록/수정/삭제 가능
- 월 공동생활비, 2인 부담금, 잔액과 정산 안내 구현
- 홈과 캘린더가 실제 데이터와 연결됨
- 알림 정책과 로컬 알림 예약·취소 코드 구현
- 공통 테마와 320~402px 반응형 디자인 적용
- 디자인 QA용 데모 데이터 준비 완료

현재 판정은 `기능 구현 완료, 외부 릴리즈 준비 중`입니다. 실제 iOS/Android 알림 검증과 릴리즈 Firebase 2계정 스모크가 끝나기 전에는 릴리즈 완료로 보지 않습니다. 측정 가능한 성공 기준과 릴리즈 게이트는 [제품 브리프와 MVP 판정 기준](../product-brief.md)을 기준으로 확인합니다.

## 후속 디자인·릴리즈 작업에서 꼭 알아둘 점

1. 현재 공통 테마와 모바일 레이아웃은 적용되어 있습니다.
2. 기능 흐름과 데이터 구조를 바꾸면 성공 기준·구현 상태 문서도 함께 갱신합니다.
3. 후속 디자인은 `src/components/app`의 공통 컴포넌트에서 시작합니다.
4. 릴리즈 후보에서는 화면별 빈 상태, 에러 상태, 로딩 상태와 접근성을 다시 확인합니다.

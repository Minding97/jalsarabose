# MVP 구현 상태

## 완료된 기능

| 영역 | 상태 | 설명 |
| --- | --- | --- |
| 로그인 | 완료 | 이메일/비밀번호 로그인, 회원가입 |
| 가구 | 완료 | 가구 생성, 초대 코드 참여 |
| 홈 | 완료 | 오늘 할 일, 지출, 냉장고, 알림 요약 |
| 캘린더 | 완료 | 지출일, 집안일 날짜, 유통기한 표시 |
| 지출 | 완료 | 등록, 수정, 삭제, 납부 완료 |
| 집안일 | 완료 | 등록, 수정, 삭제, 완료 처리 |
| 냉장고 | 완료 | 등록, 수정, 삭제, 소진/폐기 |
| 알림 | 준비 완료 | 실제 푸시 전 정책과 로컬 예약 버튼 구현 |
| 데모 데이터 | 완료 | 디자인 QA용 샘플 데이터 생성 가능 |

## 아직 남은 것

- 실제 디자인 적용
- 실제 기기에서 알림 수신 확인
- 앱 아이콘과 splash 디자인 반영
- 배포용 설정 정리
- 스토어 등록용 문구와 이미지 준비

## 이번 MVP의 의미

이제 앱은 단순 목업이 아니라 실제 데이터가 저장되고 공유되는 상태입니다.

디자인 작업은 화면 흐름을 바꾸기보다, 현재 기능 위에 사용성과 시각 체계를 입히는 단계로 보면 됩니다.

<details>
<summary>개발자가 참고할 구현 위치</summary>

- 화면: `src/app`
- 공통 UI: `src/components/app`
- 로그인/가구 설정: `src/components/auth-screen.tsx`, `src/components/household-setup-screen.tsx`
- Firebase 연결: `src/services`
- 상태 관리: `src/store/household-store.ts`
- 검증 스크립트: `scripts`

</details>

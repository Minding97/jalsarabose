# MVP 구현 상태

기준일: 2026-08-24

상태 판정과 릴리즈 여부는 [제품 브리프와 MVP 판정 기준](../product-brief.md)을 기준으로 합니다.

## 영역별 상태

| 영역 | 구현 상태 | 검증 상태 |
| --- | --- | --- |
| 로그인 | 이메일/비밀번호 로그인, 회원가입 구현 완료 | 릴리즈 Firebase 재검증 필요 |
| 가구 | 생성, 초대 코드 참여, 최대 2인 격리 구현 완료 | Rules/스모크 경로 있음, 릴리즈 2계정 재검증 필요 |
| 홈 | 오늘 일정, 지출, 냉장고, 월간 요약 구현 완료 | 데이터 연결 회귀 테스트 있음 |
| 캘린더 | 지출 납부일, 냉장고 유통기한 표시 구현 완료 | 릴리즈 후보 화면 검증 필요 |
| 지출·생활비 | CRUD, 납부 상태, 월 공동생활비, 2인 부담금, 잔액, 누적 정산 안내 구현 완료 | 단위·Rules 테스트 있음, 2계정 동시 수정 확인 필요 |
| 냉장고 | CRUD, 소진/폐기 구현 완료 | Firebase CRUD 스모크 경로 있음 |
| 알림 | 대상 계산, 로컬 예약·취소 구현 완료 | iOS/Android 실제 기기 검증 필요 |
| 디자인 | 공통 테마와 320~402px 반응형 화면 적용 완료 | `design-qa.md` 기록 있음, 릴리즈 후보 재검증 필요 |
| 데모 데이터 | 디자인 QA용 샘플 데이터 생성 스크립트 구현 완료 | 테스트 Firebase 계정 필요 |
| 집안일 | MVP 범위 제외, 화면·데이터 쓰기·알림 제거 | 안전 제거 회귀 테스트 있음 |

## 외부 릴리즈 전 남은 것

- 실제 기기에서 알림 수신 확인
- 릴리즈 Firebase에서 2계정 초대·공유·격리 확인
- 릴리즈 후보의 브라우저·모바일 접근성 회귀 확인
- 앱 아이콘과 splash 디자인 반영
- 배포용 설정과 Firestore Rules 배포 확인
- 개인정보 처리 안내와 스토어 등록용 문구·이미지 준비
- 열린 P0/P1 결함 0건 확인

## 이번 MVP의 의미

앱은 단순 목업이 아니라 실제 데이터가 저장되고 공유되는 상태입니다. 다만 구현 완료와 릴리즈 완료를 구분하며, 현재 판정은 `기능 구현 완료, 외부 릴리즈 준비 중`입니다.

후속 디자인 작업은 현재 기능 위에서 접근성과 시각 완성도를 높이는 단계로 봅니다. 기능 또는 범위를 바꿀 때는 성공 기준과 이 상태표를 같은 변경에서 갱신합니다.

# 디자인 전달 체크리스트

## 먼저 필요한 것

- 앱 전체 컬러
- 기본 폰트 스타일
- 버튼 스타일
- 입력 필드 스타일
- 카드/리스트 스타일
- 탭 바 스타일
- 상태 배지 스타일

## 우선순위

1. 공통 컴포넌트
2. 로그인/가구 설정
3. 홈
4. 지출/냉장고
5. 캘린더
6. 빈 상태와 에러 상태

## 디자인에서 꼭 정해야 할 것

- 홈의 정보 우선순위
- 초대 코드 노출 방식
- 등록 폼의 배치 방식
- 수정/삭제 액션의 위험도 표현
- 완료/소진/폐기 빠른 액션 표현
- 알림 상태의 문구와 강조 정도

## 권장 방향

- 운영 도구처럼 빠르게 스캔되는 화면
- 과한 장식보다 명확한 정보 구조
- 작은 모바일 화면에서 버튼과 입력이 눌리기 쉬운 크기
- 빈 상태 문구는 짧고 부드럽게

주요 공통 컴포넌트:

- `ActionButton`
- `FormField`
- `Card`
- `ListRow`
- `MetricCard`
- `StatusPill`
- `SegmentedControl`
- `EmptyState`

# 테스트와 데모 안내

## 현재 확인된 것

- 로그인 가능
- 가구 생성 가능
- 초대 코드 참여 가능
- 지출/냉장고 CRUD 가능
- 홈과 캘린더에 실제 데이터 반영
- 데모 데이터 생성 가능
- 웹 미리보기 가능

## 디자이너 확인용 데모 데이터

테스트 계정의 활성 가구에는 데모 데이터가 들어가 있습니다.

데모 항목 예시:

- `[demo] 관리비`
- `[demo] 장보기`
- `[demo] 우유`
- `[demo] 냉동만두`

## 웹 미리보기

개발 서버 실행:

```bash
npm run web
```

Mock 데이터로 보기:

```bash
npm run web:mock
```

## 데모 데이터 다시 만들기

```bash
SMOKE_TEST_EMAIL=<테스트 계정 이메일> \
SMOKE_TEST_PASSWORD=<테스트 계정 비밀번호> \
npm run demo:seed
```

데모 데이터만 삭제:

```bash
SMOKE_TEST_EMAIL=<테스트 계정 이메일> \
SMOKE_TEST_PASSWORD=<테스트 계정 비밀번호> \
npm run demo:reset
```

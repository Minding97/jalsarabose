# 테스트와 데모 안내

## 현재 확인된 것

- 로그인 가능
- 가구 생성 가능
- 초대 코드 참여 가능
- 지출/냉장고 CRUD 가능
- 월 공동생활비와 2인 부담금 저장 가능
- 잔액과 누적 정산 안내 표시
- 홈과 캘린더에 실제 데이터 반영
- 데모 데이터 생성 가능
- 웹 미리보기 가능

위 목록은 구현된 확인 경로를 뜻하며 최신 릴리즈 통과 선언은 아닙니다. 성공 기준과 필수 실행 증거는 [제품 브리프의 릴리즈 게이트](../product-brief.md#릴리즈-게이트)를 따릅니다.

## 디자이너 확인용 데모 데이터

테스트 계정의 활성 가구에는 데모 데이터가 들어가 있습니다.

데모 항목 예시:

- `[demo] 관리비`
- `[demo] 장보기`
- `[demo] 우유`
- `[demo] 냉동만두`

## 웹 미리보기

개발 서버 실행:

```bash
npm run web
```

Mock 데이터로 보기:

```bash
npm run web:mock
```

## 데모 데이터 다시 만들기

```bash
SMOKE_TEST_EMAIL=<테스트 계정 이메일> \
SMOKE_TEST_PASSWORD=<테스트 계정 비밀번호> \
npm run demo:seed
```

데모 데이터만 삭제:

```bash
SMOKE_TEST_EMAIL=<테스트 계정 이메일> \
SMOKE_TEST_PASSWORD=<테스트 계정 비밀번호> \
npm run demo:reset
```

<details>
<summary>개발 검증 명령</summary>

전체 검증:

```bash
npm run verify
```

Firestore Rules Emulator 검증:

```bash
npm run test:firestore-rules
```

Firebase smoke test:

```bash
SMOKE_TEST_EMAIL=<테스트 계정 이메일> \
SMOKE_TEST_PASSWORD=<테스트 계정 비밀번호> \
SMOKE_INVITE_EMAIL=<초대 참여 계정 이메일> \
SMOKE_INVITE_PASSWORD=<초대 참여 계정 비밀번호> \
npm run smoke:firebase
```

두 계정 초대와 양쪽 CRUD까지 확인하려면 네 개의 `SMOKE_*` 계정을 모두 설정해야 합니다. 계정 값이나 실행 로그의 비밀값은 문서에 남기지 않습니다.

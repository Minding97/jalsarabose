# 주요 사용자 흐름

## 1. 처음 시작

1. 앱 실행
2. 로그인 또는 회원가입
3. 가구 만들기 또는 초대 코드 입력
4. 홈 화면 진입

## 2. 가구 만들기

1. 가구 이름 입력
2. 가구 생성
3. 초대 코드 발급
4. 다른 가구원에게 코드 공유

## 3. 초대 코드로 참여

1. 로그인
2. 초대 코드 입력
3. 같은 가구 데이터에 접근
4. 지출, 집안일, 냉장고 항목 함께 관리

## 4. 생활 항목 관리

| 항목 | 주요 액션 |
| --- | --- |
| 지출 | 등록, 수정, 삭제, 납부 완료 |
| 집안일 | 등록, 수정, 삭제, 완료 처리 |
| 냉장고 | 등록, 수정, 삭제, 소진, 폐기 |

## 5. 홈에서 확인하는 것

- 오늘 챙길 일
- 다가오는 지출
- 유통기한 임박 항목
- 이번 달 집안일 균형
- 알림 준비 상태

<details>
<summary>디자인 시 주의할 흐름</summary>

- 로그인 전과 로그인 후 화면이 완전히 다릅니다.
- 로그인 후에도 가구가 없으면 탭 화면이 아니라 가구 설정 화면이 먼저 나옵니다.
- MVP에서는 사용자 1명당 활성 가구 1개를 전제로 합니다.
- 초대 코드는 6~8자리 대문자/숫자입니다.

</details>

# 주요 사용자 흐름

## 1. 처음 시작

1. 앱 실행
2. 로그인 또는 회원가입
3. 처음 시작 화면에서 새 가구 만들기 또는 초대받은 가구 참여 선택
4. 가구 이름 또는 초대 코드 입력
5. 홈 화면 진입

## 2. 가구 만들기

1. 가구 이름 입력
2. 가구 생성
3. 초대 코드 발급
4. 다른 가구원에게 코드 공유

## 3. 초대 코드로 참여

1. 로그인
2. 초대 코드 입력
3. 같은 가구 데이터에 접근
4. 지출과 냉장고 항목 함께 관리

## 4. 생활 항목 관리

| 항목 | 주요 액션 |
| --- | --- |
| 지출·생활비 | 월 예산/2인 부담금 설정, 지출 등록·수정·삭제·납부 완료, 잔액·정산 안내 확인 |
| 냉장고 | 등록, 수정, 삭제, 소진, 폐기 |

## 5. 가구 이름 수정

1. 홈에서 마이페이지 열기
2. `우리 집`의 가구 이름 수정 선택
3. 2~30자의 새 이름 입력
4. 저장 후 같은 가구를 사용하는 화면에 변경된 이름 반영

## 6. 홈에서 확인하는 것

- 오늘 챙길 일
- 다가오는 지출
- 유통기한 임박 항목
- 알림 준비 상태

## 6. 월 공동생활비 확인

1. 지출 대시보드에서 대상 월 선택
2. 2인 가구의 월 공동생활비 입력
3. 50:50 또는 직접 입력으로 두 사람의 부담금 설정
4. 부담금 합계 오류를 수정한 뒤 저장
5. 선택 월 지출 합계와 남은/초과 생활비 확인
6. 누적 지출을 기준으로 한 정산 안내 확인

<details>
<summary>디자인 시 주의할 흐름</summary>

- 로그인 전과 로그인 후 화면이 완전히 다릅니다.
- 로그인 후에도 가구가 없으면 탭 화면이 아니라 가구 설정 화면이 먼저 나옵니다.
- MVP에서는 사용자 1명당 활성 가구 1개를 전제로 합니다.
- 초대 코드는 6~8자리 대문자/숫자입니다.

</details>

# 화면별 정리

## 로그인

목적: 사용자를 식별하고 개인 데이터를 연결합니다.

필요 UI:

- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 전환 버튼
- 에러 메시지

## 가구 설정

목적: 함께 관리할 가구를 만들거나 기존 가구에 참여합니다.

필요 UI:

- 가구 이름 입력
- 가구 만들기 버튼
- 초대 코드 입력
- 참여하기 버튼
- 로그아웃 버튼

최초 진입 UI:

- 새 가구 만들기 또는 초대 코드 참여 선택
- 선택한 방식의 입력 폼
- 다른 방법 선택으로 이전 단계 이동

가구 생성 후 마이페이지 UI:

- 현재 가구 이름과 가구원 수
- 가구 이름 수정, 취소, 저장
- 가구 이름 입력 오류와 저장 결과

## 홈

목적: 오늘 확인해야 할 일을 한눈에 보여줍니다.

주요 정보:

- 가구명
- 멤버 수
- 초대 코드
- 오늘 일정
- 다가오는 지출
- 유통기한 임박 항목
- 알림 준비 상태

## 캘린더

목적: 날짜 기준으로 생활 이벤트를 모아봅니다.

표시 항목:

- 지출 납부일
- 냉장고 유통기한

## 지출

목적: 월 공동생활비, 구성원 부담금, 공동 지출과 납부 상태를 관리합니다.

대시보드 정보:

- 선택 월 공동생활비
- 두 가구원의 부담금
- 실제 지출 합계와 남은/초과 생활비
- 카테고리별 지출
- 누적 지출 기준 정산 안내

필수 입력:

- 지출명
- 금액
- 납부 날짜
- 지출 유형
- 납부 상태

월 생활비 입력:

- 대상 월
- 월 공동생활비
- 부담 방식(50:50 또는 직접 입력)
- 두 구성원의 부담금

## 냉장고

목적: 재고와 유통기한을 관리합니다.

필수 입력:

- 항목명
- 보관 위치
- 상태

선택 입력:

- 수량
- 유통기한
- 알림 여부

# 화면별 정리

## 로그인

목적: 사용자를 식별하고 개인 데이터를 연결합니다.

필요 UI:

- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 전환 버튼
- 에러 메시지

## 가구 설정

목적: 함께 관리할 가구를 만들거나 기존 가구에 참여합니다.

필요 UI:

- 가구 이름 입력
- 가구 만들기 버튼
- 초대 코드 입력
- 참여하기 버튼
- 로그아웃 버튼

## 홈

목적: 오늘 확인해야 할 일을 한눈에 보여줍니다.

주요 정보:

- 가구명
- 멤버 수
- 초대 코드
- 오늘 일정
- 다가오는 지출
- 유통기한 임박 항목
- 알림 준비 상태

## 캘린더

목적: 날짜 기준으로 생활 이벤트를 모아봅니다.

표시 항목:

- 지출 납부일
- 냉장고 유통기한

## 지출

목적: 공동 지출과 납부 상태를 관리합니다.

필수 입력:

- 지출명
- 금액
- 납부 날짜
- 지출 유형
- 납부 상태

## 냉장고

목적: 재고와 유통기한을 관리합니다.

필수 입력:

- 항목명
- 보관 위치
- 상태

선택 입력:

- 수량
- 유통기한
- 알림 여부

- 빈 상태

# Handoff: 신혼부부 동거 관리 앱 (Household Lifestyle App)

## Overview
2인 이상 공동생활자를 위한 라이프스타일 관리 앱 프로토타입. 홈, 캘린더, 지출, 집안일, 냉장고 5개 핵심 탭과 마이페이지(가구원 관리/알림 설정)를 포함한다.

## About the Design Files
이 폴더의 HTML 파일은 **디자인 레퍼런스(프로토타입)**이며, 그대로 복사해 쓸 코드가 아니다. 목표는 이 HTML이 보여주는 화면/동작을 실제 개발 환경(React Native, Flutter, SwiftUI/Kotlin, 웹 등 팀이 쓰는 스택)의 기존 패턴과 라이브러리로 재구현하는 것이다. 아직 정해진 스택이 없다면 프로젝트에 맞는 프레임워크를 새로 선택해 구현한다.

## Fidelity
**Hifi에 가까운 인터랙티브 프로토타입.** 색상/타이포/레이아웃은 최종 값에 가깝고, 탭 이동·목록↔등록/수정 전환·체크/토글·간단한 계산(정산, 수행률)까지 클릭으로 동작한다. 단, 실제 데이터 저장은 브라우저 메모리(React state)일 뿐 백엔드/DB 연동은 없다 — 이 부분이 개발자가 채워야 할 부분이다.

## Screens / Views

### 1. 홈
- 상단: 인사 문구 + 오늘 날짜, 우측 아바타(마이페이지 진입)
- 가구원 chip 목록 (이름 + 이니셜 아바타)
- "오늘 일정" 카드 (당일 캘린더 이벤트 요약, 없으면 빈 상태 문구)
- 2열 그리드: 이번 달 지출 요약 카드 / 유통기한 임박 카드
- "오늘의 집안일" 카드: 담당자 아바타 + 상태(완료/대기)

### 2. 캘린더
- 월 이동 화살표 + "YYYY년 M월" 라벨
- 요일 헤더 + 6주(42일) 그리드, 일정 있는 날 하단에 dot 표시
- 날짜 선택 시 하단에 해당일 일정 리스트 노출
- + 버튼으로 인라인 일정 추가 폼 (제목/시간 입력 → 추가/취소)
- 각 일정 항목에 삭제 버튼

### 3. 지출
- 목록/대시보드 세그먼트 탭
- **목록**: 날짜별 그룹핑된 지출 카드 (카테고리 뱃지, 제목, 결제자, 분배방식, 금액) — 클릭 시 수정 폼
- **대시보드**: 이번 달 총 지출/1인당 금액, 카테고리별 막대그래프, 정산 안내 ("A가 B에게 X원 보내면 정산 완료")
- **등록/수정 폼**: 금액, 항목명, 카테고리 chip, 결제자 chip, 분배방식(균등/직접) chip, 직접분배 시 인원별 금액 입력, 저장/삭제 버튼
- FAB(+) 버튼으로 신규 등록 진입

### 4. 집안일
- 목록/대시보드 세그먼트 탭
- **목록**: 체크박스(완료 토글), 이름, 주기, 담당자명 + 아바타
- **대시보드**: 오늘 수행률 %, 이번 주 인원별 수행 막대그래프, 로테이션 순서 리스트
- **등록/수정 폼**: 이름, 반복주기(매일/매주/매월) chip, 이번 차례 담당자 chip → 선택 시 자동 로테이션 순서 미리보기 텍스트, 저장/삭제
- FAB(+)로 신규 등록

### 5. 냉장고
- 목록/대시보드 세그먼트 탭
- **목록**: 유통기한 지남 / 임박(3일 이내) / 신선 보관 중 세 그룹으로 정렬, 각 항목에 D-day 뱃지
- **대시보드**: 전체 재고 수, 임박 건수, 분류별(채소/육류/유제품/기타) 막대그래프
- **등록/수정 폼**: 품목명, 수량, 유통기한(날짜), 분류 chip, 보관위치(냉장/냉동/실온) chip, 저장/삭제
- FAB(+)로 신규 등록

### 마이페이지 (바텀시트)
- 홈 화면 우상단 아바타 클릭 시 슬라이드업
- 가구원 리스트, 알림 설정 토글 2개(유통기한/집안일 리마인드), 가구원 초대 코드 표시, 로그아웃

## Interactions & Behavior
- 하단 5탭 네비게이션, 탭 전환 시 스크롤 상단 리셋 없음(각 화면 독립 상태 유지)
- 목록 항목 클릭 → 수정 폼, 폼 저장/취소 → 목록 복귀
- FAB는 지출/집안일/냉장고 탭에서만 노출되며 신규 등록 폼을 연다
- 캘린더 날짜 선택은 즉시 하단 리스트 갱신, +로 인라인 추가 폼 토글
- 지출: 분배방식이 "직접입력"일 때만 인원별 금액 입력 필드 노출
- 집안일: 완료 체크는 목록에서 바로 토글, 로테이션은 담당자 배열 순환으로 계산
- 냉장고: 유통기한 - 오늘 날짜 차이로 D-day 자동 계산, 지남/임박/신선 자동 분류

## State Management (프로토타입 기준, 실제 구현 시 서버 상태로 대체)
- `tab`: 현재 하단 탭
- `members[]`: 가구원 목록 (id, name, initial, 색상)
- `events{}`: 날짜(key)별 일정 배열
- `expenses[]`: 지출 항목 (title, category, amount, payerId, date, split, shares)
- `chores[]`: 집안일 항목 (title, cycle, rotation[], currentIdx, doneToday, weekDone)
- `foodItems[]`: 냉장고 품목 (name, category, qty, storage, expiryDate)
- 각 도메인별 등록/수정 폼은 `xxxForm`(열림 여부/편집 대상 id) + `xxxDraft`(입력 중 값) 상태로 관리
- **개발자 액션 필요**: 위 배열들을 실제 DB(가구household 단위로 스코프된 테이블)와 연동, 인증/가구 초대 플로우 연결, 알림 설정을 실제 push/알림 스케줄러와 연결
